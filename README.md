# 🕹️ Retro-8

Retro-8 is a [CHIP-8](https://en.wikipedia.org/wiki/CHIP-8) emulator written in Swift with my own Raylib bindings. I hope to turn into a fantasy console one day.

## ⬇️ Running a ROM

Pass a ROM file with `--load`:

```sh
swift run retro8 --load roms/hello-world.c8
```

The `roms/hello-world.c8` file is a small example ROM that draws "HELLO WORLD".
