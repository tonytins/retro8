# 🕹️ Retro-8

Retro-8 is a [CHIP-8](https://en.wikipedia.org/wiki/CHIP-8) emulator written in Swift and Raylib that I hope to turn into a fantasy console.

## ⬇️ Running a ROM

Pass a ROM file with `--load`:

```sh
swift run retro8 --load roms/hello-world.chip8
```

The `roms/hello-world.chip8` file is a small example ROM that draws "HELLO WORLD".
